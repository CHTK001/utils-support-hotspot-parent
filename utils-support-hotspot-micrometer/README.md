# utils-support-hotspot-micrometer

Micrometer metrics热点监控插件

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-hotspot-micrometer</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `MicrometerMetricsPlugin` | Micrometer Metrics 监控插件 监控 Micrometer MeterRegistry 的指标注册 @version 4.0.0.36 |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
