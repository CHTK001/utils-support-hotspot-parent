# Utils Support Hotspot Dubbo2x - Dubbo 2.x 热点监控模块

## 📖 模块说明

该模块提供 Dubbo 2.x 版本的监控支持，使用 `com.alibaba.dubbo` 包名。

## 🎯 支持版本

- Dubbo 2.6.x
- Dubbo 2.7.x

## ✨ 主要功能

- RPC 调用监控
- 服务实例追踪
- 分布式链路追踪
- 性能指标收集

## 📦 依赖

```xml
<dependency>
    <groupId>com.alibaba</groupId>
    <artifactId>dubbo</artifactId>
    <version>2.6.12</version>
</dependency>
```

## 🚀 使用方式

该模块会自动通过 Java Agent 加载，无需手动配置。

## 📝 版本历史

- 4.0.0.33 - 初始版本，支持 Dubbo 2.x
